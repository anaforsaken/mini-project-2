# BFC

Responsive fast food restaurant website built with HTML and Tailwind CSS (CDN) for CSE-2340, Mini Project 2.

## Features
- Sticky navbar with mobile hamburger menu
- Sections: Hero, Combo deals, Menu, About, Reviews, Order
- Menu category filter, add-to-order cart with live total, order form with validation
- Prices shown in Bangla numerals (৳ ১,০৯০)
- Hover effects, smooth scrolling, keyboard focus styles, reduced-motion support
- Mobile-first responsive layout

## Run
Open `index.html` in a browser (internet needed for Tailwind CDN and fonts).
